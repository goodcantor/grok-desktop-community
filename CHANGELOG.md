# Changelog

## 0.1.0-beta.1 — community preview

Initial Community distribution, based on liaan/grok-desktop v1.4.7 and the personal Custom UI improvements.

- Independent execution ownership, persistent background queues and interrupted delivery recovery.
- Unified sidebar, inline agent requests, Activity ledger and confirmed response files.
- Separate Community preferences, native shared conversations and official CLI authentication.
- Electron 44, sandboxed renderer, explicit Preview permission denial and truthful tool-terminal isolation.
- Community-only update feed and protected, mandatory multi-platform release gates.

A separate preview profile prepares unsigned/ad-hoc draft installers with manual updates and installed-payload checks. Public availability is shown in Releases. Signed releases remain blocked pending signing and platform acceptance. See docs/CUSTOM-HISTORY.md for historical predecessor notes; those are not Community release claims.
