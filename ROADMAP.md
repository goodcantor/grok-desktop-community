# Roadmap

## Public beta gate

- [x] Separate Community identity and native history compatibility.
- [x] Durable delivery recovery and explicit terminal isolation state.
- [x] Read-only native sharing preference and browser permission policy.
- [ ] Native acceptance on all four OS/architecture targets.
- [ ] Windows signing provisioned and verified.
- [ ] Apple Developer ID, notarization and stapling verified.
- [ ] Signed update acceptance between two test versions.
- [ ] First signed public beta with checksums and provenance.

## After beta feedback

Prioritize reproducible stability, accessibility, resource usage and onboarding issues. Do not promise an agent runtime, scheduler, cross-session context engine or unsupported history branching. Language expansion and additional CPU architectures need explicit product decisions and acceptance coverage.
